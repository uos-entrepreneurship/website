The official web portal for the **UOS Entrepreneurship Society** at the **University of Sahiwal**. Built to accelerator-grade standards with a dark-mode-first aesthetic, fluid inertia scrolling, and high-performance Astro Islands architecture.

---

## ⚡ Tech Stack

- **Framework:** [Astro 5.4](https://astro.build) (Zero-JS server-rendered default)
- **Interactive Islands:** [React 19](https://react.dev) + `@astrojs/react`
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com) + `@tailwindcss/vite`
- **Smooth Inertia Scrolling:** [Lenis](https://lenis.darkroom.engineering) synced to GSAP ticker
- **Scroll Choreography:** [GSAP 3.12](https://gsap.com) + ScrollTrigger
- **Typography:** Inter Variable & JetBrains Mono

## 🚀 Getting Started

### Prerequisites
- Node.js `20.x` or higher
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/uos-entrepreneurship/website.git
cd website

# Install dependencies
npm install

# Start development server
npm run dev
```

Visit `http://localhost:4321` to view the site.

---

## 📦 Building for Production

```bash
# Generate static build
npm run build

# Preview production build locally
npm run preview
```

Output is generated into `dist/`, ready for instant zero-config deployment to **Vercel**, **Netlify**, or **Cloudflare Pages**.
